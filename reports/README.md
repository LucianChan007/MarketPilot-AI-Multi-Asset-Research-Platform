# 本地报告目录说明

- `forecasts/archive/`：不可覆盖的历史预测快照，用于复盘。
- `intraday/`：当前盘中预测与其归档 / 实际行情比较结果。
- `articles/`：当前导出的微信公众号 HTML、Markdown 和曲线 PNG。
- `reviews/`：单日复盘结果、K 线图和候选模型对比。
- `unified_daily_workflow/`：统一每日流程的状态与运行日志。
- 其他带日期的 CSV / JSON / Markdown：旧的网格回测、投资报告和滚动验证结果，保留供后续追溯。

提醒：`reports/` 可能含个人研究和预测历史，不建议原样提交到公开 GitHub 仓库。
